# miscutils

> Hyperecclectic mix of cli tools.

## webshare

Instantly share a directory over the web, with QR code support.

```
$ webshare -d . -p 8080
```

![](static/webshare.png)

## fixfn

```
$ fixfn -d "REPORT FINAL 2.pptx"
renaming: 'REPORT FINAL 2.pptx' to 'report_final_2.pptx'
```
